КУРСОВИЙ ПРОЄКТ ООП — ВАРІАНТ 18 «СТРАХОВА КОМПАНІЯ»

Структура:
- InsuranceAgency.Core — Class Library з моделями, інтерфейсами, репозиторіями, бізнес-логікою та винятками.
- InsuranceAgency.Console — консольний інтерфейс; має посилання на InsuranceAgency.Core.

Як відкрити:
1. Розпакуйте ZIP-архів.
2. Відкрийте InsuranceAgency.sln у Visual Studio 2022.
3. Переконайтеся, що InsuranceAgency.Console є Startup Project.
4. Запустіть Ctrl+F5.

Збереження:
Дані автоматично завантажуються під час запуску та записуються у insurance-data.json під час вибору пункту «0. Зберегти та вийти».

Формат дат: yyyy-MM-dd (наприклад, 2026-11-14).
Формула вартості поліса: страхова сума * коефіцієнт ризику.
